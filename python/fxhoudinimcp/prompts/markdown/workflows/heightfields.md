## Everything is layers

**Almost every heightfield operation creates a new layer.** A heightfield is not
one image with a height in it, it is a stack of named layers, and terrain work is
layer bookkeeping as much as it is shaping. `heightfields/layers` is the page to
read first.

- `height` holds the elevation value per grid point, and it is what becomes displacement.
- `mask` is the layer mask nodes write and shaping nodes read. It only becomes accessible once a mask node is wired into the second input of the node consuming it.
- A **mask is a kind of layer**, not a separate concept. "Layer" is the umbrella term.
- Check what layers exist rather than assuming: the heightfield node's **Node info** lists them.

## The technique that separates working setups from fragile ones

`mask` is a single shared channel, so anything you build in it is destroyed by
the next mask node. **Copy a mask into its own named layer when you need to keep
it.** The documented example: build a mask to drive thermal erosion, copy it to a
`thermalerodabilitymask` layer, and you are then free to overwrite `mask` with
something else.

That is what heightfield_copylayer is for, and reaching for it is the difference
between a terrain you can keep editing and one where every new mask breaks the
previous shaping.

## Judgement

- Work at low resolution while establishing the shape. heightfield_resample changes it later; erosion cost scales hard with resolution and erosion is where the time goes.
- Erosion is a simulation over iterations, not a filter. Treat it as an expensive stage, cache it, and do not re-run it to change something downstream.
- Masks drive parameters, so build the mask deliberately and visualise it. heightfield_visualize exists because a mask you cannot see is a mask you cannot debug.
- heightfield_maskbyfeature (slope, height, curvature) is how you get masks that follow the terrain rather than hand-painting. Paint is for art direction, not for structure.
- Scattering onto terrain reads the layers, so scatter after shaping and masking, not before.
- heightfield_output converts to renderable geometry. Terrain stays a heightfield for as long as possible, because layers are lost on the way out.

## Order of work

1. heightfield to establish extent and resolution, deliberately coarse.
2. Base shape: heightfield_noise, projected geometry, or a file.
3. Build masks, copying any you need to keep into their own named layers.
4. Shape: erosion, slump, terracing, distortion, each read through a mask where it should be local.
5. Visualise layers and `capture_screenshot` before raising resolution.
6. Resample up, re-erode, cache.
7. Scatter and output last.
