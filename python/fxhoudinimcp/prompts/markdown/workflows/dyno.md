## Workflow

1. get_scene_info for the current state.
2. Build source geometry as a SOP chain.
3. Use the matching workflow tool. Only if none fits, wire a DOP network by hand: object, then solver, then source via volumesource or SOP geometry.
4. get_simulation_info to check state, step_simulation to advance, get_dop_object to inspect.
5. set_parameter to adjust the solver; reset_simulation after changing anything fundamental.

## Tips

- get_geometry_info on the source before simulating; get_sim_memory_usage on heavy sims.
- RBD: pack first, and use assemble to name pieces.
- Pyro: pyropostprocess shapes the look after the sim.
- FLIP: particlefluidsurface meshes the result.
- Vellum: vellumdrape settles cloth before simulating.
- Collisions: collisionsource builds VDB collision volumes from meshes.
