viewport ¶

MCP tool definitions for Houdini viewport and UI operations.

Provides tools for inspecting and controlling Houdini's viewport panes, display modes, camera assignment, screenshot capture, network editor navigation, and error node discovery.

set_viewer_context async ¶

set_viewer_context(
    ctx: Context,
    network_path: str,
    current_node: str | None = None,
    pane_name: str | None = None,
) -> dict

Point the Scene Viewer at a network, and optionally a node inside it.

set_current_network moves the network EDITOR; this moves the VIEWER. That is what decides whether a scene graph view exists, so it is the prerequisite for previewing a USD stage or setting a Hydra delegate: call this with "/stage" before set_viewport_renderer or before binding a USD camera prim.

The result reports is_scene_graph_view, which is the question you are usually really asking.

Parameters:

Name Type Description Default
network_path ¶
 str

Network for the viewer to display, e.g. "/stage".

 required
current_node ¶
 str | None

Node inside it to make current, which selects the stage a Solaris viewport shows.

 None
pane_name ¶
 str | None

Pane tab name.

 None
